5. Two independent garage approaches  
6. **Four enclosed spaces through two genuine 22×22 garages**  
7. Realistic daily maneuvering burden  
8. Each home ≥ ~18′ contiguous width + credible lower-floor plate  

D/E/F: **Original Program Gate = FAIL** (D/F on physical staging; E on architecture remaining).

### Parking Reset Gate

For the next phase only — intentionally revised parking programs (smaller boxes, tandem, covered, lift). Do **not** auto-fail a concept for lacking twin 22×22.

Per concept, define the four-space arrangement, then require:

1. FS-SUV access (survey, swept path, **20.5′ staging on declared faces**, turning)  
2. Independent approaches / bay use as claimed by the concept  
3. Two viable home plates (≥ ~18′ contiguous each; credible lower floor)  
4. Daily burden not worse than “Fair” without a documented trade  

A concept that drops twin 22×22 is scored only against the Parking Reset Gate for that concept’s declared parking program.
