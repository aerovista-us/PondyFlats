## Premise (trade accepted)

The circulation work showed that requiring ~900 SF of conventional ground-floor living per unit **fights the parcel**. For two ~1,800-SF homes with two genuine 22×22 garages on Lot 2:

> **Parking/access owns the ground plane first.** Residential architecture uses the remaining ground floor plus substantial living-over-garage / second-floor area.

This is **not** accepting G1-A's awkward 11′ residential ribbon. J1 is a clean-sheet duplex family generated from the proven Access A skeleton.

| ID | Treatment | Upper strategy |
| -- | --------- | -------------- |
| **j1a** | LOG Bridge | Continuous upper bridge over both garages; ground pods anchor entries |
| **j1b** | Staggered Volumes | Penn-forward upper block (A) + rear stepped upper (B) — breaks single-bar silhouette |
| **j1c** | Central Spine | Shared upper plate over both bays; separate ground entry pods read as two homes |

## Kill criteria

1. **Ribbon kill** — no ground or upper mass &lt; **16′** minimum width
2. **Access A lock** — garages, drive, and FS-SUV paths unchanged
3. **Setback / survey** — all masses inside working envelope
4. **Drive clearance** — ground pods do not encroach 12′ drive corridor

SF band misses → **REVIEW** (Pass 2A conceptual tolerance). Ribbon or access **FAIL** → stop.

## Critical design question — answered

**NO** (Image 4.2 ownership gate). Honest J1-B remains garage/access-first; Building B is subordinate; pedestrian identity is weak. Windows and trim would not change that hierarchy.
