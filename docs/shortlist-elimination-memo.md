## Seven scoring criteria

1. Site fit / circulation
2. Buildability
3. Floor-plan quality
4. Pennsylvania street presence
5. Privacy / outdoor living
6. Resale / architectural character
7. Cost / complexity penalty

Ratings are qualitative (Strong / Good / Fair / Low / Moderate / High) — not a spreadsheet winner.
