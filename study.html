Pass 1.5 workflow

Pass 1.5 re-seats all 12 concepts inside the polygon-accurate survey and working setback envelope. Geometry PASS is separate from design refinement — a concept can pass geometry while still needing design judgment before Pass 2.

SOT survey polygon (frozen) → polygon-accurate setbacks (planning assumptions) → concept geometry (7 established + 5 challengers) → validation metrics (PASS / REVIEW / FAIL) → locked Final Three: E2 / G1 / V2 → Pass 2: SUV paths → Access A/B/C → J1 Pass 2A massing (trade accepted) → elevation / floor plan
