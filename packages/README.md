# Standalone packages

Generated by `npm run export`. Clients open a **client** folder. Presenters keep the sibling **presenter** folder.

| Folder | Audience | Open |
| ------ | -------- | ---- |
| `design-1-client/` | Client / internal review of the drawings | `index.html` |
| `design-1-presenter/` | You | `index.html` + `talking-points.html` |
| `design-2-client/` | Client / internal review of the drawings | `index.html` |
| `design-2-presenter/` | You | `index.html` + `talking-points.html` |
| `design-3-client/` | Client / internal review of the drawings | `index.html` |
| `design-3-presenter/` | You | `index.html` + `talking-points.html` |

Do not zip workbench.html, lot.html, or the rest of the repo into a client handoff.
`lot.html` is a fallback lot sketch in this repo, not LotScope. It is not inside these folders.
