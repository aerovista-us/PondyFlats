Why the current work has value

What has already been resolved enough to inform the field

These are not permit approvals. They are early answers that are unusually useful because they give contractors and trades something concrete to react to before a conventional drawing set is finished.

Site / concrete / garage door

Real vehicle and garage scale

The model uses a 20.5×8.0 ft full-size vehicle, two full 22×22 garage plates, 20 ft concept overhead openings, a 10 ft shared lane and a 25 ft local maneuver apron. The second vehicle remains parked while each inbound stall path is tested.

Builder / framing / MEP

Home programs fit the promoted shells

Both homes carry three-bedroom planning diagrams with explicit room and stair connectivity checks. That is more useful than a simple square-footage box because framing, mechanical and plumbing discussions can start around an actual circulation concept.

Architect / window / exterior trades

Elevations and axon share opening geometry

Entries, concept windows and garage openings come from one coordinate model. A change is meant to propagate consistently instead of leaving an elevation, plan and 3D view quietly disagreeing with each other.

Site / utilities / ownership

Who uses what is explicit

North Garage B belongs to Home B; south Garage A belongs to Home A; Pennsylvania is the only modeled vehicle access. That gives site, utility, pedestrian and maintenance discussions a clear starting relationship.

Current position

What still needs to move before Design 4 is ready to freeze

The remaining work is narrower than the earlier discovery phase. We are refining operational and jurisdiction-sensitive interfaces rather than searching from scratch for a basic two-home / four-stall concept.

Primary release gate: outbound vehicle proof. The repository’s circulation standard requires audited departure back to Pennsylvania as well as arrival. Until that is demonstrated, Design 4 remains NEAR-PASS / ITERATE.
Operational refinement

Garage B deserves another pass

The B-North inbound path currently uses four gear changes. B-South has only 0.073 ft — about 0.9 in — of modeled door-crossing margin, so it is correctly treated as marginal rather than presented as comfortable.

Building / fire / drainage

The rear-garage gap is an explicit coordination item

Approximately 2 ft between the detached garages still needs jurisdictional review for wall/eave projections, fire treatment, roof water and drainage. Keeping this visible now is more useful than discovering it during permit detailing.

Zoning / civil

Accessory-yard assumptions remain conditional

The site geometry uses the current accessory-structure planning hypothesis, but parcel-specific zoning, grade, drainage, snow storage, utilities, easements and driveway engineering remain professional work.
