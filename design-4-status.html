Active technical review · not released

Design 4 is being refined, not watered down.

The core objective remains two full 22×22 detached rear garages with four practical enclosed stalls and Pennsylvania-only access. Review found several places where the proof and drawings need to be stronger. We are fixing those before calling Design 4 complete.

What stays locked

Two full 22×22 garages

We are not shrinking the garage plates to make the site easier.

Four practical enclosed stalls

This remains a Design 4 requirement. We will validate both stall positions in each garage rather than soften the goal.

Rear accessory strategy

The garages stay at the far rear using the accessory-structure setback study as the planning basis.

Pennsylvania-only vehicle access

No neighboring access or alternate street entry is being introduced to rescue the geometry.

What we are working on now

Driveway curve
Widen/re-shape the approach and maneuver pavement so the continuous full-size vehicle envelope clears the south boundary with a real margin, not a coarse sampled approximation.
Four-stall proof
Model both parking positions inside each 22×22 garage, including usable offset positions and the 16 ft door approach, so the four-stall claim is backed by geometry.
Floor-plan circulation
Repair upper-level circulation so every bedroom and hall is reachable without passing through private rooms, then add a connectivity gate to prevent regressions.
Site pavement
Replace the thin diagrammatic driveway ribbon with the actual usable driveway/apron/maneuver envelope shown at vehicle scale.
Elevations
Rebuild Home B elevations from the true L-shaped exterior edges instead of a bounding rectangle.
Opening audit
Make doors/windows use the shared red/blue opening contract across the architectural views and strengthen QA around it.
Package export
Wire Design 4 into the normal repository export command so the standalone customer package cannot silently go stale.

Why Design 4 is not released yet

The current package renders and its first automated QA passed, but technical review identified proof gaps that matter. We are treating those findings as design work, not paperwork. The active concept remains promising; the release gate stays closed until the revised vehicle, parking, plan, elevation and package checks pass.

Still conditional: parcel-specific accessory zoning, the approximately 2 ft garage-to-garage condition, building/fire/eave/drainage review, structure, MEP, civil, survey/easements, energy and permit validation. This page is a design-development progress update, not an approval or construction document.
